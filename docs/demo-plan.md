# Approved homepage plan
Mode: Persuade. Visual priority with clear contact; Slovenian.
1. Navigation and hero: art-directed desktop/mobile image, three retracting panels, staggered heading, subtle desktop parallax. No loader or scroll lock.
2. Trust: since 2009, combined trades, material advice, waste removal for renovations.
3. Five service cards: roofing/renovations, carpentry, sheet metal, flat roofs, Velux windows; each with supplied image and form preselection.
4. Inquiry: heading, telephone, email on left; validated name, phone, optional email, service and message on right. Demo status only.
5. Why us: genuine project photograph, concise company profile and three strengths.
6. Six manufacturer logos: Bramac, Tondach, Creaton, Tegola, Decra, Trimo. Moving strip with pause and reduced-motion grid.
7. Process: inquiry, solution, quote/schedule, delivery. No guaranteed prices or timings.
8. Three original project photos in asymmetric gallery with keyboard-friendly dialog.
9. Three paraphrased original testimonials, source disclosed, no ratings or invented identity.
10. CTA and contact footer.
Framework: Next.js App Router, strict TypeScript, Tailwind v4, custom shadcn-style CVA button, Radix dialogs, GSAP/ScrollTrigger, Motion, Lenis, React Hook Form/Zod. Static server content with client interaction leaves. Self-hosted fonts. Preview noindex in metadata, robots.txt and HTTP headers.
